# 💎 JAwelsDiamonds E-Commerce

**JAwelsDiamonds** is a web-based jewelry store built using **ASP.NET Web Forms** as part of our *Pattern Software Design* course project. It implements a layered architecture with design patterns such as Repository, Factory, and Handler.

Users can browse products, add items to the cart, and complete purchases. Admins have full access to manage products, handle orders, and generate sales reports.

---

## ✨ Features

### 🔐 Authentication & Roles
- **Guest**: Can browse products
- **Customer**: Register, login, update profile, shop, and view order history
- **Admin**: Manage products and transactions, view reports

### 💍 Product Management
- Admins can **Create, Read, Update, Delete (CRUD)** product data (name, description, price, image)

### 🛒 Shopping Cart & Transactions
- Add items to cart
- Checkout
- View transaction history and details

### 📊 Reporting
- Admins can generate transaction reports using **Crystal Reports**
